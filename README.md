# rock-paper-scissors-game
A simple, console-based Rock Paper Scissors game built with JavaScript. This was a project to practice functional programming, loops, and user input handling.

## How to Play
1. Open the project in your browser.
2. Open the **Developer Tools** (Right-click > Inspect > Console).
3. The game will play for **5 rounds**.
4. Type `rock`, `paper`, or `scissors` when prompted.
5. The final winner will be announced in the console after 5 rounds.

## Lessons Learned
* Implementing **loops** to repeat game logic.
* Using **conditional statements** to determine a winner.
* Handling **user input** via the browser `prompt()` method.
* Managing **global state** to track scores across multiple rounds.
